# hq tracker

Tracker de obiceiuri bune și rele, cu temă alb-negru, gândit întâi pentru telefon.

- **Obiceiuri bune** (sport, citit…) și **obiceiuri rele** pe care vrei să le lași (fumat, alcool…)
- Contor live: de câte zile, ore, minute și secunde respecți obiceiul
- Praguri (1 zi, 1 săptămână, 1 lună, 1 an…) cu bară de progres
- „Am cedat” / „Am ratat” salvează seria în istoric și repornește contorul; recordul rămâne
- Bani economisiți pentru obiceiurile rele (cost pe zi, în MDL)

## Cum o folosești

Un singur fișier: `index.html`. Îl deschizi în browser și gata, fără instalare.

Datele se salvează în `localStorage`, adică doar în browserul și pe dispozitivul pe care folosești aplicația.

## Publicare cu GitHub Pages

1. În repository: **Settings → Pages**
2. La **Source** alegi **Deploy from a branch**, branch `main`, folder `/ (root)`, apoi **Save**
3. După un minut aplicația e la `https://<utilizator>.github.io/hq-tracker/`

Pe telefon, deschide linkul și alege **Adaugă pe ecranul principal**. Aplicația se deschide ca una instalată.
